## Project Description
CommunityHub is a modular React social feed application built collaboratively using a Git feature-branch and Pull Request workflow. I initialized the React + Vite project under `frontend/`, built the core layout components (`Header`, `Sidebar`, `Footer`), implemented the post feed and creation components (`PostList`, `PostCard`, `CreatePost`), and wrote automated unit tests for the post utilities.

## Technologies Used
- React (JSX, Functional Components)
- Vite
- JavaScript (ES6+)
- CSS3
- Vitest
- React Testing Library
- Git & GitHub

## Features
- Responsive page layout with navigation header, sidebar, and footer.
- Dynamic community post feed displaying user posts.
- Interactive post creation form.
- Reusable and modular React components.
- Automated unit tests for post utility functions.
- Organized frontend structure for User and shared component integration.

## How to Run
1. Clone this repository:
   `git clone https://github.com/rahabkungu/iyf-s12-communityhub-team-rahabkungu.git`
2. Navigate to the frontend folder:
   `cd iyf-s12-communityhub-team-rahabkungu/frontend`
3. Install dependencies:
   `npm install`
4. Start the development server:
   `npm run dev`

## Lessons Learned
While developing CommunityHub, I gained practical experience building applications with React and Vite. I learned how to create reusable functional components, use JSX, organize project files into folders, and connect different components to build a complete application. I also improved my understanding of rendering dynamic content, creating post-related functionality, and writing automated tests using Vitest. Additionally, I learned how to use Git and GitHub feature branches and Pull Requests to manage code changes during collaborative development.

## Challenges Faced
One of the main challenges I encountered was organizing the React project and understanding how different components should be structured. I also faced difficulties integrating components such as Header, Sidebar, Footer, PostList, and PostCard while ensuring they worked together correctly. Writing unit tests for the post utility functions was another challenge because I needed to understand how to test different functions and verify their expected results. Managing Git branches and Pull Requests also required careful attention. I addressed these challenges by organizing the project into smaller components, checking imports and component structure, practicing writing tests, and using Git commands to manage changes.
